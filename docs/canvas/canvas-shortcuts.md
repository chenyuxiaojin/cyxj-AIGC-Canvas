# 画布快捷键

本文档与画布「…」›「快捷键」弹窗内容一致；弹窗改动时同步更新这里。

## 视图

- `Space` + 拖动：临时切换选择 / 移动模式（工具栏最左的「选择 / 移动」是常态切换）。
- 中键拖动：平移画布。
- 鼠标滚轮：缩放画布。
- 缩放坞：小地图、重置视图、缩放滑杆。

## 选择

- 拖动空白处：框选节点。
- `Shift` + 拖动空白处：追加框选。
- `Shift / Ctrl / Cmd` + 点击节点：追加或取消选择。
- `Ctrl / Cmd` + `A`：全选。
- `Esc`：取消选择，并关闭当前浮层。

## 创建与编辑

- 双击空白处：添加节点（七类）。
- 双击节点：预览图片 / 视频 / 全景，编辑文本，展开或收起图片组。
- 双击标题：重命名节点。
- 右键节点：复制副本、删除；视频节点另有截取首帧 / 尾帧 / 当前帧。右键连线：删除连线。
- `Ctrl / Cmd` + `G`：把选中节点建成组（唯一创建方式）。
- `Ctrl / Cmd` + `C` / `V`：复制 / 粘贴节点，或粘贴系统剪贴板里的文本、图片。
- `Ctrl / Cmd` + `Z`：撤销；`Ctrl / Cmd` + `Shift` + `Z` 或 `Ctrl / Cmd` + `Y`：重做。
- `Delete / Backspace`：删除选中的节点或连线。

## 播放

- `Space`：播放 / 暂停选中的视频节点。
- `Shift` + `Space`：串联试剪播放 / 暂停。
- 全屏预览里 `←` `→`：切换同组图片。

## 素材

- 拖入图片 / 视频 / 音频文件：添加到画布。
- 拖动左侧「资产」页签的卡片到画布：插入素材。
- 「…」›「添加本机素材」：从本机选择文件。

## 撤销和重做范围

撤销和重做会记录画布节点、连线、视口、背景模式和助手会话变化。画布项目名称、账号状态、全局 AI 配置和「资产」页签的保存操作不属于当前画布历史。
