## 原生接口定位与新实测

老狗公开前端的 Seedance 默认上游及中文帮助文案明确指向 `https://vinted.cam`。其 [原生文档](https://vinted.cam/developers) 和 [OpenAPI](https://vinted.cam/openapi.json) 使用 `/v1/files` 上传图，`POST /v1/videos` 创建任务（HTTP202），`GET /v1/videos/{id}` 轮询，`/signed_url` 或 `/file` 下载。四个模型ID与当前密钥一致；2.5仅30秒、720p。默认值不能证明服务端实际账号URL。

按该协议提交一个合法、不带图片的街道空镜控制请求（含必需幂等头）到老狗，`/v1/videos` 仍返回404 `Videos API is not supported for this platform`；简化聊天仍404 `server_error: Not Found`。空聊天对象返回400 `model is required`，证明该路由存在；`/v1/files`、catalog/pricing/balance均404。不是只缺末尾v1，也不是六图或长提示词造成上述控制请求失败。

当前事实是服务端平台能力拒绝。推断为Seedance分组/账号尚未正确转发原生视频服务；无服务端源码和管理权限，不能确定内部配置哪项错误。未向Vinted发送老狗密钥，也未生成任务或下载。证据已归档到案例5 `03-生成/01-四月进酒吧/接口核对/原生接口定位/接口定位结果.md`，画布说明节点同步更新。
