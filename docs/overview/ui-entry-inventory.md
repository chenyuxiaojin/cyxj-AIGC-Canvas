# 界面入口清单

本清单是 [PRD 第 10 节](product-requirements.md#10-界面收敛与减法验收) 的执行基线：每个界面入口登记现状与去向，每个动作只有一个家。界面改动先改本清单，再改代码。

**计数口径**：只数用户可点击的入口（按钮、链接、菜单项、页签、卡片动作）。弹窗内部的表单字段、只读文字、分隔线不计；键盘快捷键和手势不计入入口数，但登记在第 G 节。行号以 2026-09-17 源码为准，实现后按截图复核。

**去向标记**：`一档` 工具栏常露 ｜ `二档` 「+ 更多」｜ `三档` 「…」｜ `页签` 左侧面板 ｜ `节点` 选中节点工具栏或节点内 ｜ `条件` 只在触发时出现 ｜ `仅快捷键/手势` ｜ **下线**。
